# Häufige Fragen

Klick auf eine Frage, um die Antwort aufzuklappen.

Brauche ich irgendwelche Skills?

Nein. Der Hackathon ist auch für komplette Einsteiger*innen gedacht. Wenn du nicht weiterkommst, helfen dir vor Ort alle gerne weiter.

Wie melde ich mich an?

Gar nicht. Komm einfach vorbei!

Was ist die Aufgabe?

Die Aufgabe ist frei: Ihr baut, was euch Spaß macht. Hauptsache, es steckt ein bisschen Embedded und KI drin. Wenn euch nichts einfällt, geben wir euch vor Ort Denkanstöße.

Muss ich Hardware mitbringen?

Nein, die Hardware stellen wir: Mikrocontroller wie den Seeed XIAO ESP32-S3, Sensoren, Displays, Bauteile und Werkzeug. Lötkolben stehen bereit. Was es alles gibt, steht in der Hardware-Liste. Mitbringen musst du nur deinen Laptop und ein USB-C-Datenkabel.

Welche Software brauche ich?

Das ist euch überlassen. Wir empfehlen die Arduino IDE oder PlatformIO. Wie du sie einrichtest, steht unten unter Vorbereitung.

Wie bereite ich mich am besten vor?

Das Wichtigste zuerst: Richte dir rechtzeitig einen KI-Assistenten ein. Die kostenlosen Studierenden-Zugänge brauchen bis zu einer Woche, bis sie freigeschaltet sind (siehe KI-Assistent einrichten). Danach arbeitest du die Checkliste unter Vorbereitung durch: Laptop und Kabel einpacken, Entwicklungsumgebung installieren und einmal ein Testprogramm kompilieren. Dann kannst du am Abend direkt loslegen.

Wie groß sind die Teams? Kann ich auch alleine kommen?

Ihr arbeitet in Teams aus 2-3 Personen. Die Teams bilden wir vor Ort, du kannst also gerne alleine kommen.

Wann und wo genau?

Am Freitag, 04.12.2026 ab 18:00 Uhr in den Räumen F1.-208 und F1.-110. Das Ende ist offen.

Wie lange geht der Hackathon?

Die ganze Nacht. Jede*r bleibt so lange, wie er oder sie möchte. Unser Schlafplan wurde übrigens auch noch nicht gefunden.

Was kostet die Teilnahme?

Für Snacks und Getränke ist gesorgt. Kosten entstehen höchstens für einen KI-Assistenten. Keine Lizenz? Kein Problem: Als Studierende*r bekommst du Chat AI der Academic Cloud (unsere Empfehlung), GitHub Copilot und Gemini kostenlos. Du musst es nur rechtzeitig beantragen. Alles dazu und was ein Abo sonst kostet, steht unten unter KI-Assistent einrichten.

# Vorbereitung

Am besten alles schon vor dem Hackathon erledigen, dann könnt ihr direkt loslegen. Die Häkchen merkt sich dein Browser.

  • Steckdosen gibt es, eine Mehrfachsteckdose ist aber nie verkehrt.

  • Achtung: Viele Kabel können nur laden. Mit so einem Kabel taucht das Board am Laptop gar nicht auf. Hat dein Laptop nur USB-A, brauchst du ein Kabel USB-A auf USB-C.

  • Welche, ist dir überlassen. Wir empfehlen eine von diesen beiden:

    Arduino IDE (am einfachsten für den Einstieg): Download unter arduino.cc/en/software (Version 2.x).

    PlatformIO (für alle, die schon mit VS Code arbeiten): in VS Code die Erweiterung PlatformIO IDE installieren.

  • Arduino IDE: Unter Datei → Einstellungen (macOS: Arduino IDE → Settings) bei „Zusätzliche Boardverwalter-URLs“ eintragen:

    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

    Dann im Boardverwalter nach esp32 suchen und das Paket esp32 by Espressif Systems installieren.

    PlatformIO: Ein neues Projekt anlegen, als Board Seeed Studio XIAO ESP32S3 und als Framework Arduino wählen. In der platformio.ini steht dann:

    [env:seeed_xiao_esp32s3]
platform = espressif32
board = seeed_xiao_esp32s3
framework = arduino

    Beim ersten Bauen lädt PlatformIO die Toolchain herunter. Das dauert ein paar Minuten, also besser zu Hause im WLAN erledigen.

  • Arduino IDE: Als Board XIAO_ESP32S3 auswählen, dann Datei → Beispiele → 01.Basics → Blink öffnen und auf ✓ (Überprüfen) klicken. PlatformIO: Im neuen Projekt einmal auf ✓ (Build) klicken. Läuft das ohne Fehler durch, ist alles bereit. Ein Board brauchst du dafür noch nicht.

  • Die Getting-Started-Seite von Seeed erklärt Pins und Upload. Tipp: Lässt sich das Board nicht flashen, beim Einstecken die BOOT-Taste gedrückt halten.

  • Wichtigster Punkt: Die kostenlosen Zugänge für Studierende brauchen bis zu einer Woche. Unsere Empfehlung ist Chat AI der Academic Cloud mit der VS-Code-Erweiterung Continue. Die Anleitung mit fertiger Konfiguration steht direkt unten unter KI-Assistent einrichten.

  • In der Hardware-Liste siehst du, welche Sensoren, Displays und Boards es gibt.

# KI-Assistent einrichten

Ein KI-Assistent ist beim Hackathon sehr empfohlen. Er hilft dir beim Programmieren, erklärt Datenblätter und findet Fehler.

[ WARN ] Die kostenlosen Zugänge für Studierende müssen erst bestätigt werden. Das kann bis zu einer Woche dauern. Beantrage sie also rechtzeitig! Sonst musst du dir ein Abo kaufen, was aber auch kein Problem ist.

## 1. Empfohlen: Chat AI der Academic Cloud

Chat AI ist ein KI-Dienst für Hochschulen, betrieben von der GWDG auf Servern in Deutschland. Für Studierende ist er kostenlos. Mit deinem Hochschulkonto kannst du ihn sofort im Browser nutzen. Mit einem eigenen API-Schlüssel bindest du ihn direkt in VS Code ein, ganz ohne Hin- und Herkopieren.

  1. API-Schlüssel beantragen (rechtzeitig!): Auf der Seite des KISSKI LLM Service auf „Book“ klicken und das Formular ausfüllen. Nimm dieselbe E-Mail-Adresse wie bei deinem Academic-Cloud-Konto. Als Zweck kannst du den Hackathon angeben.

  2. Schlüssel testen: Im Terminal eingeben (DEIN_KEY ersetzen). Kommt eine Liste mit Modellen zurück, funktioniert er.

    curl -s https://chat-ai.academiccloud.de/v1/models -H "Authorization: Bearer DEIN_KEY"

  3. Continue installieren: In VS Code mit Strg+Shift+X die Erweiterungen öffnen, nach Continue suchen und installieren.

  4. Konfiguration einfügen: Im Continue-Panel auf das Zahnrad klicken. Dann öffnet sich die Datei config.yaml (unter Linux/macOS ~/.continue/config.yaml, unter Windows %USERPROFILE%\.continue\config.yaml). Ersetze den Inhalt durch die Konfiguration unten, trag bei allen drei Modellen deinen Schlüssel statt DEIN_KEY ein und speichere.

    # Continue-Konfiguration für Chat AI (GWDG)
name: GWDG Chat AI
version: 1.0.0
schema: v1

models:
  # Coding-Modell: Chat, Code ändern und Autovervollständigung
  - name: Qwen3 Coder Next (GWDG)
    provider: openai
    model: qwen3-coder-next
    apiBase: https://chat-ai.academiccloud.de/v1
    apiKey: DEIN_KEY
    roles:
      - chat
      - edit
      - apply
      - autocomplete

  # Großes Modell für schwierige Fragen (langsamer)
  - name: Qwen 3.5 397B (GWDG)
    provider: openai
    model: qwen3.5-397b-a17b
    apiBase: https://chat-ai.academiccloud.de/v1
    apiKey: DEIN_KEY
    roles:
      - chat
      - edit

  # Schnelle Alternative mit Denkschritten
  - name: DeepSeek V4 Flash (GWDG)
    provider: openai
    model: deepseek-v4-flash-0731
    apiBase: https://chat-ai.academiccloud.de/v1
    apiKey: DEIN_KEY
    roles:
      - chat
      - edit

    Lädt Continue die Datei nicht neu, in VS Code einmal Developer: Reload Window ausführen (Strg+Shift+P).

  5. Loslegen: Im Continue-Panel oben das Modell Qwen3 Coder Next (GWDG) auswählen.

    • Chat: Fragen im Panel stellen, mit @ hängst du Dateien an.
    • Strg+L: markierten Code in den Chat schicken.
    • Strg+I: markierten Code direkt im Editor ändern lassen.
    • Tab: Vorschlag der Autovervollständigung übernehmen. Die ist bei der GWDG noch Beta. Wenn sie stört, die Zeile - autocomplete entfernen.

[ WARN ] Der Schlüssel gehört nur dir: nicht weitergeben und nicht in ein Git-Repository hochladen. Die config.yaml liegt außerhalb deiner Projekte, dort ist er sicher.

Welche Modelle es gerade gibt, zeigt der Test aus Schritt 2. Modelle wie gemma-4-31b-it oder qwen3.8-27b verstehen auch Bilder, z.B. ein Foto von deinem Steckbrett. Mehr dazu in der Doku der GWDG.

## 2. Weitere kostenlose Zugänge für Studierende

  • GitHub Copilot: Bei GitHub Education als Studierende*r verifizieren (am besten mit Hochschul-Mail und Studienbescheinigung), dann unter github.com/settings/education/benefits Copilot aktivieren. Anleitung
  • Google Gemini: Ein Jahr Google AI Plus kostenlos über gemini.google/de/students. Das Angebot gilt bis 31.12.2026. Du brauchst eine Zahlungsmethode, also danach rechtzeitig kündigen.
  • Ohne Verifizierung: Copilot Free und Google Antigravity sind kostenlos, haben aber knappere Limits.

## 4. Andere KI-Tools in VS Code einrichten

Klick auf ein Tool für die Anleitung.

GitHub Copilot (GPT, Claude und Gemini in einem)

Copilot ist in VS Code schon eingebaut. Unten links auf das Konto-Symbol klicken und mit GitHub anmelden, danach öffnest du den Chat mit Strg+Alt+I. Im Chat kannst du zwischen Modellen von OpenAI, Anthropic und Google wählen. Welche verfügbar sind, hängt von deinem Plan ab. Anleitung

OpenAI Codex (GPT)

In VS Code unter Erweiterungen (Strg+Shift+X) die Erweiterung Codex von OpenAI installieren, das Codex-Symbol in der Seitenleiste öffnen und mit deinem ChatGPT-Konto anmelden. Die Erweiterung braucht mindestens ChatGPT Plus. Anleitung

Claude Code (Claude)

In VS Code unter Erweiterungen nach Claude Code suchen und installieren. Eine Datei öffnen, oben rechts auf das Claude-Symbol klicken und mit deinem Claude-Konto anmelden. Du brauchst ein bezahltes Abo, also mindestens Claude Pro. Claude Code gibt es auch fürs Terminal. Anleitung

Google Gemini (Antigravity)

Achtung: Die Gemini-Erweiterung für VS Code (Gemini Code Assist) und die Gemini CLI funktionieren seit Juni 2026 nicht mehr für private Konten, auch nicht mit Google AI Pro. Google verweist stattdessen auf seinen eigenen Editor Antigravity. Den gibt es als App, IDE und CLI. Er ist kostenlos mit wöchentlichen Limits, mit Google AI Pro bekommst du mehr. Alternativ nutzt du Gemini-Modelle über GitHub Copilot.
