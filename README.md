# Events
Hier werden alle Events der Fachschaft IT gelistet.

Seite: https://fachschaft-it-hochschule-esslingen.github.io/Events/

## Aufbau

| Ordner / Datei | Inhalt |
| --- | --- |
| `index.html`, `index.css` | Übersichtsseite mit Links zu allen Events |
| `assets/` | Gemeinsames Layout (`css/base.css`), Hell/Dunkelmodus (`js/theme.js`) und FSIT-Logos |
| `_template/` | Vorlage für neue Event-Seiten (wird nicht veröffentlicht) |
| `spieleabend/`, `kneipentour/`, `hackathon/`, `it-girls/` | Je eine Event-Seite |

Alle Seiten haben dasselbe Layout: FSIT-Logo oben links, Hell/Dunkel- und Zurück-Button oben rechts, Footer mit Instagram und Moodle.

## Neues Event anlegen

`_template` kopieren, umbenennen und die Schritte in [`_template/README.md`](_template/README.md) befolgen.
